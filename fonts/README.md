# Fonts

Fonts aren't included, because their licences don't allow sharing them. Qitaf works without them and uses your system's Arabic fonts. Put yours in this folder for the intended look.

**Thmanyah (the main font):** free from [Thmanyah](https://ask.thmanyah.com/hc/en-001/articles/45993930027281-Thmanyah-Font-for-Everyone). Enter your email and the files arrive by email. Don't share or re-upload them.

**Warsh Qur'an font:** the installer downloads this for you.

**To add any font:** copy its `.ttf`, `.otf` or `.woff2` file here, directly in this folder, then tell Claude:

> I added the font `<file name>` to the fonts folder. Add it to Qitaf's font lists for captions and titles.
